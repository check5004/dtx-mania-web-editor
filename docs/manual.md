# DTX Web Editor 説明書

DTXMania 向けの、ブラウザで動くドラム譜面エディタの、すべての機能の説明です。はじめての人は [README](../README.md)（図と画面写真で紹介しています）から読んでください。

**公開ページ:** https://check5004.github.io/dtx-mania-web-editor/

曲・譜面・音は、ブラウザの中と、あなたが選んだフォルダ（つないだときは Google Drive も）だけで扱います。このサイトのサーバーには何も送りません。

アプリのホームのいちばん下に、説明書（README）と GitHub のこのリポジトリへのリンク、いまの版を出しています（README は日本語だけです）。

## 言語（日本語 / English）

- 画面は日本語と US 英語を切り替えられます。初めて開いたときは英語です。
  - 切り替えは、ホーム画面の右上・メニューの「表示」・設定の「言語」のどれからでもできます。選んだ言語はこのブラウザに覚えます。
- AI が書く文も画面の言語で返します（曲情報のコメントと検索の途中経過、レベル判定の理由、ガイドライン、難易度の方針、小節の生成とフレーズ候補の名前・理由）。
- 開発のきまり: 画面に出す文は `tr('日本語', 'English')` でその場に両方書きます。`node scripts/i18n-check.mjs` で英語の無い日本語を探せます。テストは日本語で動かします（`src/test-setup.ts`）。耳コピ精度テストのページ（bench.html）は開発用なので日本語のままです。

## iPad・タブレット

- 指で使う端末（iPad の Safari など）では、自動でタブレット用の画面になります。設定の「タッチ操作」で「タブレット」「デスクトップ」に固定もできます（PC でタッチの画面を試すときも）。縦・横どちらでも使え、向きを変えるとその場で並びが変わります。
- 譜面: タップで置く、ダブルタップで消す（下に「元に戻す」）、1本指でなぞってスクロール（はじくと慣性）、ピンチで拡大、長押しでチップ・空いた所・小節番号のメニュー、長押しのままなぞって移動、2本指タップで元に戻す・3本指タップでやり直す。左のレールで「置く／選ぶ」、グリッド、フラム、強さ（強・中・弱）、ベロシティを切り替えます（縦が足りないとき＝下のトラックやシートを高くしたときは、入らない物を「その他」にまとめます）。Apple Pencil で描くと、ペンで置いて指でスクロールする使い方に自動で切り替わります。
- パネル: 横は右のレールから1つずつ開き（譜面が狭くなるときは上に重ねる）、縦は下からのシート。シートは「タブだけ・細い・低い・半分・大」で止まり（つまみをドラッグ、はじくと次の高さ、タップで開け閉め）、タブごとに最後の高さを覚えます。中のパッドとトラックは高さに合わせて並び替わります（細い＝パッドを横1列12個・トラックは上の帯と1本、低い＝キット4×3を詰める）。原曲の波形・ステムなどのトラックは下から引き出し、横の帯はトラック1本ずつの高さで止まります。
- 上の再生の帯: 幅が足りないとき（縦・iPad mini・Split View など）は、マスターの音量をミックスの小窓へ移し、「追従」を ☰ の再生のメニューだけにし、ミックスをアイコンだけにして詰めます。ミックスの小窓のレーンは、押すとミュート・長押しでソロです。DTXMania風プレビューの全画面には ▶（再生・停止）が出ます。
- 入力パッド: キットの並び（12個・並べ替えられる。スネアの枠は左半分がリム）かレーンの並び（HH・LP・SD は上下2つ）。叩いたら鳴らすだけ／ステップ入力（▶ に置いて進める）／録音（カウントイン付き、指の遅れを補正。設定の「パッド」で測れます）。
- iPad でできないこと: フォルダを選ぶこと（曲は ZIP で開き、保存も ZIP で共有・ダウンロード）、電子ドラム（Web MIDI）、YouTube のタブの音の共有（映像のずれは ± で手で合わせる）。ステム分解はメモリが少ないので SCNet small を勧めます。
- ほかの画面（ホーム・設定・曲情報・音源ライブラリ・ステム・テンポ・AI難易度生成・ガイドライン）も、ボタンを指で押せる大きさにし、縦では1列に並べ替えます。テンポは小節線のつまみをドラッグ・ピンチで拡大・アンカーは長押しで外し、大きな TAP でBPMを測ります。
- Safari（とホーム画面のアプリ）: 確かめているのは Chrome です。Safari は実機で確かめていないので、ホームに「うまく動かないときは Chrome を」の案内を出します（閉じたら出しません）。音が出ないときは、もう一度 ▶ を押す・消音（コントロールセンターのベル）をオフにする・設定の「音の出力」でテスト音を鳴らし、出力の様子を見る・「音の出力を作り直す」を試してください。OGG の音は iPadOS 18.4 より前の Safari では鳴りません。Safari 向けの作りの決まりは [docs/safari.md](safari.md)。

## iPhone・スマホ

- 指で使う端末で、画面の短い辺が 600 より狭いと、自動でスマホ用の画面になります（設定の「タッチ操作」で「スマホ」に固定もできます）。タブレット版の決まりの上に作っていて、PC・iPad の画面は変わりません。iPhone では案内の文の「iPad」を「iPhone」と書きます。
- 縦: 上に曲名・元に戻す・やり直す・保存、その下に道具の帯（置く／選ぶ・グリッド・フラム・強さ・原曲の打点の列・追う）、下に再生と6つのタブ（パッド・トラック・音・原曲・耳コピ・確かめる）。タブを押すと下からシートが出ます（つまみのタップで低い・高い、下へはじくと閉じる）。音量は 🔊 から小さな窓で変えます。メトロノームは再生のバーの 🔊 の隣のボタンで鳴らし・止めます（横では右のパネルの 🔊 の隣。音量は 🔊 の窓の「メトロノーム」の行）。
- 置き方: 譜面に触れている間は指の上の吹き出しでレーンと位置を見せ、動かして合わせ、離すと置きます（設定の「置き方」で、タブレットと同じ「すぐ置く」にもできます）。ダブルタップで消す、長押しでチップ・空いた所・小節番号のメニューが下から出ます。選ぶと、グリッド1つ・レーン1つずつ動かす・コピー・削除・その他のバーが出ます（縦は下の道具の帯と入れ替わるので譜面は動かず、選ぶのをやめると道具の帯に戻ります。横は譜面の上端）。
- 横: 左のレールに道具、右からパネルを譜面に重ねて出します。原曲の打点と波形の列も出せます。向きを変えても、開いていたタブはそのままです。横にしたとき 1 小節が入りきらない拡大なら、1 小節が入るまで自動で縮めます（縦に戻すと元の拡大に。横の間に拡大を変えたら、そのままにします）。
- 特殊ノーツ（クラップなど）は PC と同じく種類ごとの列（CLP など）で見せ、パッドのシートのキットの下に種類のパッドを足します（試し打ち・ステップ・録音で置け、ステップの「消す」は特殊ノーツも消します）。
- 音の切り出しは全画面で、縦は波形を上、横は左に止めて、切り方・元・聴く・切り出す所の一覧は下（横は右）でスクロールします。下のトラックが無いので、譜面の右の原曲の列（打点・波形）を長押しして「ここの音を切り出す…」からも開けます。
- TAB補完・小節の生成（✨）・フレーズ候補: 点線の候補を見ながら選べるよう、譜面の上には重ねません。TAB補完は譜面の下の端の細い帯に、写した元・見込み・候補の切り替え（‹ ›）・AIに聞く・入れる（1小節だけ）・✕ を並べます（点線の頭が帯の陰になったら帯の上まで送り、点線が画面の外にあるときは帯の「↑ 小節 …」を押すとそこへ送ります）。小節の生成とフレーズ候補は譜面の下にパネルを出して譜面を縮め、作っている小節が見える所へ送ります（開くと下のシート・横の右のパネルは閉じ、閉じると戻します）。候補を出している間、お知らせは画面の上に出します。
- スマホでは使わないもの: ステムの分解（分けたステムは曲の ZIP ごと持ってきて足せます）、電子ドラム（iPhone は Web MIDI が無い）、曲フォルダを開くこと（ZIP か、DTX と音のファイルをまとめて選ぶ）、YouTube の自動合わせ（± で手で合わせる）。
- 横向きで使うもの: テンポと開始位置、難易度ガイドライン。AI難易度生成は縦では難易度を1つずつ大きく見せ、横にすると並べて聴き比べます。縦でも横でも、作る難易度ごとのめやす（目標レベル）を − ＋（押し続けると続けて動く）か、数字を押して打って変えられます（縦は並べた譜面の上の帯、横は左の難易度のカード）。キーボードが出ても画面は縮めず、打っている欄が見えたままにします。
- お知らせは 2 行までに縮めて出し、文を押すと全文（もう一度押すと縮める）、× で閉じます。
- ほかの画面（ホーム・設定・曲情報・音源ライブラリ・ステム・AI難易度生成）もスマホの幅に並べ替えます。設定は一覧から1つずつ開き、ステムはトラックごとに波形を出します。音源ライブラリの縦は、出典を 1 つの選ぶ欄に、楽器と音色のタグを横にスクロールする小さなボタンにして、一覧を高くします（保存の空きは一覧の下）。
- ホーム: Safari のタブで開いたときの「ホーム画面に追加」の案内は、よい点と手順を畳んでおき（「よい点と追加のしかたを見る」で開く）、「曲を開く」が最初の画面に入るようにしています。iPhone のホームには「Safari ではまだ確かめていません」の案内を出しません（PC・iPad は出します）。
- 画面の上端と切り欠き: 縦では、iOS の Safari が画面の上端にかけるぼかしが上のバーにかからないよう、上端に上のバーと同じ色の帯を置いています（Safari はその色をステータスバーの裏まで伸ばし、ぼかしを出しません）。横では、ホームと各ページを左右の切り欠きの内側に収めます。

## アプリとして使う（ホーム画面に追加・オフライン）

- iPad・iPhone: Safari（または Chrome）の共有ボタン › 「ホーム画面に追加」。ホーム画面の「DTX Editor」から開くと Safari のバーが無い全画面になり、iPad の大きさ・向きに合わせた起動画面が出ます。Safari のタブで使うと「Safari を7日使う間に一度も開かないと保存した物が消される」決まりがありますが、ホーム画面のアプリは対象外です。ただしホーム画面のアプリと Safari は保存が別なので（最近の曲・音源ライブラリ・設定・AI のキー）、どちらか一方で使ってください。
- PC: Chrome・Edge ではホームの「インストール」（またはアドレスバーのボタン）で専用の窓のアプリになります。Mac の Safari は「ファイル › Dock に追加」。
- オフライン: 一度開くと、エディタの画面と内蔵キットの音（約 3.6 MB）を端末に入れ、ネットが無くても開けます。採譜・ステム分解のエンジン（WASM、15〜30 MB）とモデルは使ったときに残します。AI・曲情報の検索・YouTube はネットが要ります。
- 新しい版: 画面はネット優先で読むので、つながっていれば開くたび・読み込み直すたびに最新の版になります（つながらない・4 秒で返らないときは端末に入れてある版）。開いたままのときは 30 分ごと・画面に戻ったとき・ネットにつながったときに確かめ、新しい版があれば「新しい版（vX）があります ― 読み込み直す」と知らせます。読み込み直すかは選べ、曲を開いているときは確かめてから、変更を自動保存に残して読み込み直します。設定の「アプリとして使う」で、いまの版の確認と「新しい版を確かめる」ができます。
- しくみ（開発）: `src/pwa/`。ビルドのとき `src/pwa/vite-plugin.ts` が dist の目録を作り、`src/pwa/sw.ts` を `dist/sw.js` にまとめます。キャッシュは `dtxe-app-` で始まる名前だけを使い、版ごとのキャッシュを新しい順に3つ残します（開いたままの古い画面が、あとから読む JS を失わないように）。Service Worker が扱うのは同じオリジンの `/dtx-mania-web-editor/` の中と Google Fonts だけで、AI・YouTube・Google のログイン・モデルの置き場などほかのオリジンには手を出しません。開発サーバー（`npm run dev`）では入れません。アイコンと iPad の起動画面は `node scripts/make-pwa-images.mjs` で作り直せます（Playwright を使います）。

## おまかせで準備（原曲・動画・ステムから、ボタン一つで打ち込み始めまで）

- 原曲の音声ファイル・動画・Moises などで分けたステムをホームに落とす・選ぶ（曲フォルダを開いて DTX が無いときも）と、「おまかせで準備」の画面が出ます。「おまかせで準備する」を押すと、次を順に済ませて、最初の譜面（既定は MASTER）を曲の頭の小節から打ち込める所で開き、保存します（PC で開いた曲フォルダならそこへ、それ以外は本体へ）。
  - 動画から音を取り出す（動画のとき。OGG にして原曲に、動画は背景動画にも）
  - 曲名・アーティスト・画像（タグと iTunes で。設定に AI のキーがあれば、AI の Web 検索で背景画像と公式 YouTube も。1 曲 4 セントほど）
  - テンポと曲の頭（BPM と曲が始まる所を見つけ、原曲を置けるいちばん小さい小節番号にそろえる。曲の頭の前の小節は、原曲の頭を置くための空きの小節）
  - 試聴（サビを探して、選曲画面で流れる試聴を全部入りの音から作る）
  - ステム分解（ドラムとドラム抜きに。ゲームの BGM はドラム抜きにし、エディタでは両方を鳴らす。いちばん時間がかかり、iPad では 10 分を超えることも。スマホはメモリが足りないので出しません。分けたステムを一緒に選べば、ドラム抜きの BGM を作れます）
  - ドラムの打点（分けたドラム、無ければ原曲から拾って「原曲の打点」の列に）
- やることは全部入った状態で出るので、外したい物だけ外します（外した物は、あとでエディタからいつでもできます）。最初に作る難易度も選べます。「自分で入れる」は今までの新しい譜面の画面（選んだ原曲・ステムの種類はそのまま入れて開きます）。
- ステムから始めるとき: 名前（Moises の「曲名_キック_mixed.mp3」など、英語の名前も）から種類を見分けて並べ、その場で選び直せます。キック・スネア・ハイハット・シンバルのように細かく分けたドラムは合わせて 1 本のドラムとして打点・スペクトル・テンポに使い、ドラム以外を合わせてゲームの BGM（ドラム抜き）にします。メトロノームは「使わない」にし、名前から分からない物は「その他」にして黄色で知らせます。原曲のファイルも一緒に選べばそれを原曲に、無ければ全部を合わせた音を原曲にします。ステム分解は飛ばすので、30 秒ほどで開きます。PC はドラムとドラム以外の 2 列、iPad・iPhone は 1 列で、行ごとに「BGM に」「打点・スペクトル」を出します。
- 準備中: 終わった物から結果を出し、進めている物には進み具合と経過の時間を出します。テンポが決まったら、待つ間に「クリックと聴く」で曲の頭の 1 小節前から聴き、×2・÷2・頭を 1 拍前に・後ろに で直せます（直した分はすぐ譜面に入り、聴いていれば今の所から聴き直します）。「やめる」は、ここまでの分も残さずにホームに戻ります（20 秒より長く進めていたら確かめます）。準備の間は自動保存をしません。
- 終わったら: エディタの上に「準備ができました」の帯を出し、できた物・できなかった物（と、あとでやり直せること）・保存した所を並べます。テンポはここでももう一度聴いて直せ、「テンポ合わせを開く」で細かく合わせられます。× で閉じるといつもの画面です（聴いていたら止めます。ほかの譜面を開いても閉じます）。
- iPad・iPhone: 準備の間は画面をつけたまま、このアプリを開いておいてください（ほかのアプリに切り替えると止まることがあります）。iPhone は下から出るシートで、「おまかせで準備する」をいつも下に出し、準備中は波形の代わりに大きなボタンで聴いて直します。
- しくみ（開発）: 順に呼ぶ所は `src/app/setup.ts`（入口は `src/app/setupEntry.ts`、テンポを聴いて直す所は `src/app/setupTempo.ts`）、画面は `src/ui/SetupSheet.tsx`（最初の画面）・`SetupProgress.tsx`（準備中）・`SetupReady.tsx`（帯）。

## 基本の編集

- 曲フォルダを開いて、DTXの読み込み・編集・保存ができます。
  - 譜面が2つ以上あるフォルダでは、どの難易度を開くかを BASIC → ADVANCED → EXTREME → MASTER の順（上のバーの難易度の切り替えと同じ）で聞きます。
  - Chrome と Edge では、曲フォルダに直接上書き保存できます。
  - フォルダに同じファイルが大文字・小文字だけ違う名前であれば（`SET.def` など）、その名前のまま書き換えます（DTXMania は大文字・小文字を区別しないので、もう1つ作らない）。
  - そのほかのブラウザでは、保存はダウンロードになります。
- 文字コードは Shift_JIS と UTF-8（BOM付き・BOMなし）を自動で判定して読みます。
- 保存はいつも Shift_JIS・CRLF です（DTXMania がそのまま読める形式）。
  - 譜面に書くファイル名に Shift_JIS で書けない文字（♡・é・絵文字など）があると、DTXMania では「?」になって読めません（試聴や原曲が鳴らない）。保存・書き出しの前に、ファイルの名前を読める名前に変え（♡→`_`、é→e、〜→～）、どの難易度の譜面と作業ファイルも新しい名前にします。前に保存して「?」になった名前も直します。新しく置く音声ファイル・名前を付けて保存する譜面も、読める名前にします。
  - 選曲画面の試聴（#PREVIEW）が空なら、保存・書き出しの前に原曲（ドラム入り）を入れます（DTXMania は試聴が無いと選曲画面で何も鳴らしません）。入れたあとで空にすれば、そのままにします。
- エディタが解釈しない行もそのまま残して保存します。#RANDOM/#IF、BGA、ギター・ベースのチップなどが対象です。
- 譜面は縦スクロールで、下から上へ進みます。
  - 10レーンで、4シンバル構成（左シンバル・HH・右シンバル・ライド）に対応しています。
  - チップはレーンの色です。HHオープンは DTXMania と同じシルバー（HHクローズは水色）で、全体マップ・下のトラック・ベロシティの列・DTXMania風プレビュー・AI難易度生成の列・タブレットのパッドでも同じ色です。
  - **スネアのリム**（クロススティックの「カッ」）は、スネアのレーンに薄いクリーム色で真ん中に点の付いたチップです。譜面ではスネアのチャンネル（12）のまま音（WAV）だけ違うので、DTXMania ではスネアとして叩け、鳴るのはリムの音です。エディタはリムの音の WAV 番号でリムと見分けます（WAV の行のラベルかファイル名に「Rim」「Side Stick」「Cross Stick」「リム」などがあるもの）。スネアと同じファイルをリムに使うときは、別の番号にラベル「Snare Rim」を付けて登録します。
  - グリッドは 1/4〜1/64 と3連で、ズームと全体マップがあります。
- チップの置き方と操作
  - クリックで置き、ダブルクリックで消します（1回目のクリックで置いたチップは消しません）。右ボタンを押したままチップをなぞると、なぞったチップをまとめて消します。
  - Shift+クリックで HHオープン・左バスドラム・スネアのリムを置きます。
  - 範囲選択、ドラッグや矢印キーでの移動、コピーと貼り付け、Undo/Redo ができます。Undo/Redo で保存したとき（開いたとき）と同じ中身に戻れば、保存していない印（●）は消えます。
  - チップを別のレーンへ動かすと（ドラッグ・← →・タブレットとスマホの選択バー）、音もそのレーンの音になります（ベロシティはそのまま。右クリックの「レーンを変える」と同じ）。ドラッグでは、チップが動き出したときと別のレーンに入ったときに動かした先の音を鳴らすので、うっかり触って動かしても気づけます（クリックだけ・同じレーンの中で時刻を動かしている間は鳴らしません。← → と選択バーは動かしたあとに鳴らします）。上のバーの「ミックス」の「チップを置いた・動かしたときに音を鳴らす」で切れます。
  - 範囲選択やチップのドラッグの途中でホイールでスクロール・ズームしても、押した所は譜面に付いてきます（選ぶ範囲は譜面の上の範囲）。譜面の上端・下端に寄せると自動でスクロールし、範囲選択・チップの移動・ループの端・END・ベロシティの直線と鉛筆がマウスに付いてきます。範囲選択の間は、選ばれるチップをその場で選んだ色で見せます。
- 上のメニュー（ファイル・編集・表示・再生・ツール）は、ふつうのデスクトップのソフトと同じように使えます。
  - 1つ開いたら、ほかのメニューの名前にマウスを乗せるだけで切り替わります。名前を押したまま項目までなぞって離しても実行できます。
  - キーボードでは ← → で隣のメニュー、↑ ↓ で項目、Enter で実行、Esc で閉じます。開いている間はチップを置くキーや Space は効かず、Ctrl・Alt 付きのショートカットはメニューを閉じてそのまま効きます。
  - メニューの外をクリックすると閉じます（そのクリックではチップを置きません）。項目の幅は中身に合わせて広がり、折り返しません。
  - 画面が狭いときは、上のバーの幅を測って、ロゴの文字 → 難易度名（短い名前に）→「AI難易度生成」の文字（アイコンだけに）→ 曲の画像 → 曲名 の順に畳みます。
  - その下の操作バー（再生・BPM・ループ・グリッド・入力・ベロシティ）も、はみ出すときは「速度」「グリッド」「入力」「ベロシティ」の見出しと「ループ」の文字 →「テンポ合わせ」と BPMタップ・フラムの文字（絵だけに）→ すき間 の順に畳みます（1440 幅では BPMタップ・フラムの文字まで、1366・1280 幅では絵だけ）。説明はマウスを乗せると出ます。それでも入らない幅では横にスクロールします。
  - 右のパネルの「操作のしかた」（マウスとキーの早見）はパネルのいちばん下にあり、見出しを押すと畳めます（畳んだかどうかは覚えます）。チップを選んでいないときは、選んだチップの欄は出しません。
  - 譜面の右の BGA の列は、左の「画像」タブの「BGA の列」で 自動・出す・出さない を選べます（表示メニューの「BGA・動画の列を出す」は出す・出さないの切り替え）。自動は、BGA のある曲で、原曲の列（打点・波形）に重ならずに入るときだけ出します（1440 幅で左右のパネルを開いていると隠れます。「画像」タブにそのことを出します。タブレットはレーンを狭めて出し、スマホは出しません）。「出す」は狭くても出し、原曲の波形の右側に重ねます。
  - 譜面の右の列が全体図の下に隠れないよう、幅が足りないときは、自動の BGA の列を隠したうえで、強さのレーン（強さの編集のとき。60px まで）→ 原曲の波形の列（60px まで）→ ドラムのレーン（32px まで）の順に細くします。ドラムのレーンは、細くすれば全部入るときだけ細くします（入らないときはそのままの幅で、パネルを閉じると右の列が見えます）。強さの編集のときは、いちばん右の強さのレーンを見せるため、細くできるだけ細くします。
- 右クリックのメニュー（右クリックした物に合わせて、マウスのすぐ横に出ます）
  - チップ：ベロシティ（強・中・弱は押すと決まって閉じる。±・スライダー・ホイールは開いたまま聴きながら微調整）、HHクローズ/オープン・左ペダル/左バスドラム・スネア/リムの切り替え（リムにするとリムの音に、戻すとスネアの音に替わります）、レーンを変える（同じ時刻のまま、音もそのレーンの音に）、種類（通常・不可視・音だけ）、フラムにする／1打に戻す、コピー・切り取り・削除。選んでいるチップを右クリックすると選んでいるもの全部が対象です。エフェクトのテンプレートは「エフェクト ›」の小メニューに入れています（マウスを乗せると右に開き、ほかの項目に移ると閉じます。タブレットは押すと開きます）。
  - 何もない所：グリッドをボタン1回で切り替え（通常・3連・5/7連）。その小節のチップが今のグリッドに乗っていないときは、全部乗る細かさに印を付けます。レーンの上なら、ここにフラムを置く。ほかに、ここから再生・この小節をループ・ここに貼り付け・この小節のチップを選ぶ。
  - 小節番号の列・✨：この小節を AI で生成・再生・ループ・チップを選ぶ・セクション名・前の小節を写す・小節の挿入と削除。
  - ループの帯（譜面の左端・全体図・下のトラックの上の帯）：ループを消す・オン/オフ・ここを A/B にする。END の札：曲の終わりの決め方。
  - メニューの外をクリックすると閉じます（そのクリックではチップを置きません）。Esc でも閉じます。
- BPM変化（#BPMzz と ch08）と、小節ごとの拍子（ch02）を扱えます。
- 原曲（BGM）とチップ音を同期して再生できます。
  - 動画（MP4 など）からも始められます。ホームに動画を落とす・選ぶと（おまかせで準備の画面から。「自分で入れる」でも同じ）、音だけを取り出して動画と同じ名前の OGG（品質6。DTXMania で読めない文字は読める文字に）にし、それを原曲にした新しい譜面を作ります（MP4 のタグの曲名・アーティストも入れます）。動画は、DTXMania の曲データと同じく BGA の動画（#AVI01・原曲と同じ所にチャンネル 54 のチップ）にもします（作るときに外せます。DTXMania の曲データにある MP4・AVI などは最初からオン、DTXMania で流れるか確かめていない WebM・MOV はオフ）。編集中に原曲の読み込み・差し替え・ドロップで動画を選んだときも、取り出した OGG を原曲にします（BGA はそのまま）。取り出した OGG はふつうの原曲なので、ステム分解・スペクトル・原曲の打点・波形にそのまま使えます。読むのはブラウザなので、Chrome・Edge は MP4・MOV・WebM を読めます（AVI・WMV は読めないので MP4 に）。音の無い動画（曲データの bg.mp4 など）は知らせて止めます。中身は `src/audio/videoAudio.ts`。
  - Space で再生・停止。止めると再生位置は青い ▶（再生を始める位置）に戻ります（DAW の「停止時に開始位置に戻る」と同じ）。譜面の表示は止めた所のままなので、聴いていた所をすぐ直せます。A–B ループ中も ▶ に戻り、▶ がループの外なら A から再生して ▶ も A に移します。
  - Shift+Space（⏸）はその場で止めて ▶ をそこへ移すので、次はそこから続けて再生できます。
  - 再生中に小節番号の列・波形・下のトラックをクリックすると、そこへ ▶ を移して続けて再生します。
  - F5 は曲の頭から（▶ も頭へ）、F6 は ▶ から再生し、F7 で止めます。Home・⏮ で ▶ を曲の頭へ。
  - 上のバーの難易度（同じ曲フォルダの BASIC〜MASTER など）は、再生中に押しても止まらず、その場から切り替えた譜面のチップを鳴らします。原曲は途切れません。▶・表示の位置・拡大・A–B ループ・音量ミキサーの設定もそのままです（テンポが違う譜面では同じ秒の所）。難易度ごとに SE（原曲のドラムなど）の音量が違う譜面では音量だけを変え、原曲の置き方（ファイル・位置）が違う譜面では、その位置から短いクロスフェードでつなぎ替えます。
  - 原曲は曲で1つ：原曲を替える操作（原曲のカードの「差し替え」・ステムの「書き出してエディタに反映」・「ドラム抜きを BGM に反映」）は、同じ原曲を使っていたほかの難易度の譜面も同じ原曲にします（保存していない続きも。変えるのは各譜面の原曲の #WAV の行だけで、ほかの行・コメント・文字コードはそのまま）。試聴（#PREVIEW）が空か前の原曲を指していれば、試聴も新しい原曲（ドラム入り）にします（ドラム抜きにしたときは、試聴は前の原曲のまま）。Ctrl+Z・知らせの「元に戻す」で一緒に戻ります。前から難易度によって原曲のファイルが違う曲は、原曲のカードに知らせが出て、「そろえる…」で選んだ原曲にそろえられます（鳴らし始める位置と音量は難易度ごとのまま）。
  - 曲情報（曲名・アーティスト・試聴・画像など）とテンポ（BPM・BPM 変化・原曲の開始位置）も曲のもの：変えると、変える前に同じだったほかの難易度の譜面にも入れます（テンポ合わせの「エディタに反映」・ずれの「直す」・タップ・BPM の欄・BPM 変化を置く、も同じ。変えるのは各譜面のその行だけ）。前から違う難易度はそのまま。Ctrl+Z で一緒に戻り、知らせの「この難易度だけにする」でほかの難易度だけ戻せます。レベル・#PATH_WAV・拍子は難易度ごと。難易度によって違う曲は、曲情報の画面・テンポ合わせの画面に知らせが出て、「この難易度にそろえる」でそろえられます。
  - 画面下のトラック（原曲・ステム・譜面の音）とメトロノームがあります。メトロノームは上のバーの「再生」メニューからも切り替えられます。
- 曲フォルダに音が無いレーンでは、内蔵の合成ドラムキットの音を使います。保存するときに WAV ファイルとして曲フォルダへ書き出します。
- 編集中の譜面はブラウザ内に自動保存し、「最近の曲」から続きを開けます。「最近の曲」には曲ごとに1つ（最後に開いた難易度）が並びます。ほかの難易度の保存していない続きは、上のバーで難易度を切り替えると開きます。
  - PC のホームでは、最近の曲があればいちばん上に 3 列で 2 行まで出し（残りは「すべて表示」）、曲の画像（#PREIMAGE、無ければ #STAGEFILE。曲を開いている間に小さくして控えに入れておくので、フォルダの許可が切れても出ます）・曲名・アーティスト・BPM・Lv・場所・いつ を並べます。長い名前は詰めて、Lv と「いつ」は切りません。
  - 保存していない変更があるまま、ほかの曲・難易度を開くときは「保存して続ける」「保存せずに続ける」「やめる」を聞きます。保存して続けるは、いつもの保存（初めてなら保存する場所を選ぶ）をしてから開きます。保存をやめた・できなかったときは開きません。保存せずに続けると、いまの変更は「最近の曲」の自動保存にだけ残ります。
  - 新しい曲を初めて保存して曲フォルダができても、書き写した原曲・ステムは同じ音として扱い、原曲の解析・ドラムの採譜・スペクトルをやり直しません。
- **フラム**（両手でほんの少しずらして叩く2打）：グリッドを変えずに、同じレーンに2打をほんの少しずらして置けます。
  - 上のバーの「フラム」をオンにすると、クリック（入力の「キー」も）でフラムを置きます。Ctrl+クリック（Mac は ⌘+クリック）は1回だけその逆です。置く前に2打の位置を薄く出します。
  - 置いたチップや選んだチップは Alt+F（編集メニュー・チップの右クリックのメニューでも）で、フラムにする／1打に戻すを切り替えます。レーンの何もない所の右クリックのメニューの「ここにフラムを置く」でも置けます。1打に戻すときは拍の上の方を残し、ベロシティは2打の強い方にします。
  - 「フラム」の ▾ で置き方を選べます。「1打目を拍の上に」（既定。2打目をすぐ後ろへ）と「2打目を拍の上に」（1打目をすぐ前へ。叩くタイミングどおり）です。間隔の「自動」は、その所の BPM で約40ミリ秒にいちばん近い細かさ（184BPM なら 1/32、138BPM なら 1/48）です。1/24〜1/192 に決めることもできます。先に鳴る1打目のベロシティは2打目の 70%（変えられます）。
  - テスト用の6曲（作者5人）の譜面のフラムは、1打目を拍の上に置き、2打目を 1/32（184BPM・41ms）や 1/48（138BPM・36ms）後ろに書いてありました。既定はこれに合わせています。
  - 譜面では、先に鳴る1打目を少し細く描きます（読み込んだ譜面のフラムも）。
  - フラム（手のレーンの、前後のチップから離れたすばやい2打）は両手で叩くので、「連打が速すぎます」の警告にしません。等間隔の速い連打は今までどおり警告します。
  - 入力の「録音」では、グリッドでは分けられないすばやい2打（60ms 以内）を、後の1打で前の1打を消さずにフラムにします（▾ で切れます）。
- **特殊ノーツ**（クラップ・タンバリン・カウベル・シェイカーなど、ドラムのレーンに無い音）：エディタでは種類ごとに分けて見せ、ゲームでは「行き先」のレーンのチップ（または叩かない「自動で鳴らす」の SE）にします。
  - 見分け方: #WAV のラベル（コメント）を先に、無ければファイル名（clap・tambourine・cowbell・shaker など）で。ハイタムなどに置いたクラップは、譜面を変えずにクラップの列（PC・スマホ）か、行き先のレーンに種類の色で重ねて（iPad）見せます。初めて分けたときはお知らせを出し、「元に戻す」でその曲だけ分けるのをやめられます（表示メニューでも切り替え）。
  - 種類ごとに行き先のレーン・音・キー（Q W E R）・MIDI のノート（GM の 39・54・56・70）を決められます（列の見出し・左のキットの「特殊ノーツ」・フッターの「特殊ノーツ N」から）。行き先を変えると置いてあるチップも動き、同じ時刻にほかのチップがある所は「自動で鳴らす」か「消す」を選べます。Ctrl+Z で行き先の決めも一緒に戻ります。
  - 右クリック: チップは「特殊ノーツにする」「ふつうのチップに戻す」「このチップを自動で鳴らす／叩くに戻す」、列の何もない所は「ここに置く」「自動で鳴らして置く」。クラップの所にハイタムを置いても、クラップは消さずに自動で鳴らすにします。
  - 決めは作業ファイル（.dtxe.json）に残し、譜面にはふつうのチップと #WAV のラベルだけを書きます（作業ファイルが無くても、ラベルとファイル名で同じに見えます）。内蔵キットのクラップなどの音は GeneralUser GS の6キットにあり、ほかのキットはスタンダードかエレクトロ（電子音のキット）の音を使います。
- **音の切り出し**（ステム・原曲から、チップを置いた所の音を WAV にして使う）：チップと下のトラックの波形（ステム・原曲）・譜面の右の原曲の列の右クリック（スマホ・タブレットは長押し）「この所の音を切り出す…」「ここの音を切り出す…」、特殊ノーツの設定と左のキットの「ステムから切り出す」から開きます。
  - 元はドラムのステムが先です（無ければ原曲。「ステムに分解…」で分けると、分け終わってからこの画面に戻ります）。候補はほかのチップと重ならない所から並べ、鳴り始めの 2 ms 前から次の音の 16 ms 手前まで切ります（長さは手でも、波形の右の青い線のドラッグでも決められます）。低い音を弱める（150 Hz より下。バスドラムの混ざりを減らす）・音量をそろえる（−1 dB）・フェードアウト・モノラルを選べます。
  - 切り始めは「切り始め」の − ＋（1 ms ずつ）か、波形の左の青い線のドラッグで、前後 100 ms までずらせます（ずらすと元の鳴り始めを点線で見せます。長さが自動なら終わりはそのまま）。
  - 「重ねてきれいにする」で、鳴り方の似た所をそろえて平均し、ハイハットの残りなど毎回は鳴っていない音を小さくできます。似た所が見つからなければ 1 か所から切り出すのをすすめます。
  - 切り出した音・元の所（前後 1 秒）・この音で 2 小節を鳴らして確かめられます。
  - 使い道は、特殊ノーツの種類の音・新しい特殊ノーツ・レーンの音（スネア・リムなど）・WAV に足すだけ。WAV 16bit を曲フォルダ（#PATH_WAV の中）に置き、強さの違いは #VOLUME の違いで写します。ファイル名はその種類と読める名前にします（clap_曲名.wav など）。タグを付けてライブラリにも入れられます。Ctrl+Z で譜面・これから置く音・印がまとめて戻ります。
  - 切り出した音は WAV の一覧に「切り出し」の印が付き、キットを替えてもまだ置いていない音を消しません。
  - **切り出した音を直す**: 使ったあとでも、チップの右クリック（長押し）の「切り出した音を直す…」、左のキットのレーンの音の「直す」、WAV の一覧の「切り出し」、特殊ノーツの設定の「切り出した音を直す…」から、前と同じ所・同じ切り方で開き直せます。「作り直す」で同じファイルを書き直すので、譜面は変えずに、その音のチップがみな新しい音で鳴ります（元に戻すで前の音に）。切り方は作業ファイル（.dtxe.json）に残します。v0.47.0 より前に切り出した音は切り方が残っていないので、その音を使っている種類・レーンの初めの切り方から開きます。
- **エフェクト**（ハイカット・ローカット・ピッチ。DTM ソフトのオートメーションのように、曲の時間に沿ったカーブで引く）：E キー・編集メニュー・再生のバーのベロシティの隣の ⌒ で開きます（E か Esc で閉じる）。
  - スペクトルの列が広がってカーブの列になります。クリックで点を足し、ドラッグで動かし（Shift で縦か横だけ）、Delete か右クリックで消します。値は右のパネルの ‹ ›（← →）で 1 段ずつ、次の点までの形は なめらか・ゆっくり・急に・S字・そのまま から選べます。
  - 種類はハイカット・ローカット（24 dB/oct。境目の強調は なし・少し・強め）とピッチ（半音ずつ、−12〜+12）です。ハイカット 14 kHz 以上・ローカット 40 Hz 以下はかけません。
  - DTX には音を加工する仕組みが無いので、カーブのかかる所のチップごとに「かけた音」を作って、そのチップの WAV を替えます（DTXMania 側は何もいりません）。かかるかどうかは時間とカーブのレーン（初めは全部のレーン）で決まり、かけている所に置いた・動かした・貼り付けたチップもすぐかけた音になります。Ctrl+Z 1 回でカーブとチップの音が一緒に戻ります。
  - 値は 1/6 オクターブ（粗い 1/3・細かい 1/12）ごとに丸めて、同じかけ方の音は 1 つにします。シンバルなど長く鳴る音は余韻もカーブどおりにかけます（右のパネルで切れます）。WAV の番号が残り 100 を切ると知らせます。
  - チップを選んで右クリックの「エフェクト ›」のテンプレート（だんだんこもる・だんだん開く・こもって戻る・ずっとこもる・ローカット・ピッチ）で、選んだチップの時間にカーブを引きます。「原曲から読み取る」で、原曲の高い音・低い音の変わり方からカーブの案も出せます。
  - 下のトラックの「エフェクト」で全体のカーブを見られ、「切って聴く」で元の音と聴き比べられます。WAV の一覧は「エフェクト」で絞り込め、かけた音は元の音の下にまとめます。
  - 保存すると、かけた音を曲フォルダの fx/ に書き出し（元が wav なら wav、ほかは ogg）、譜面の #WAV の前の行に「;fx 元の音 かけ方」を書きます。どの譜面も使わなくなった、エディタが作ったかけた音は fx/ から消します。カーブは作業ファイル（.dtxe.json）に残します。
  - 前から同じカーブだったほかの難易度にも、保存のときに同じカーブを入れます（譜面は変わった行だけ書き換え、音はその譜面のチップで作ります）。知らせの「この難易度だけにする」で、ほかの難易度は元のファイルに戻ります。
  - タブレットも同じ画面です（タップで点を足し、ドラッグで動かし、長押しのメニューで消す）。スマホは見る・聴くだけです。
- **曲の終わり（END）**：譜面の白い線と小節番号の列の「END」の札が曲の終わりです。DTXMania はこの小節線で演奏を終え、再生もここで止まります（END より後から再生したときは原曲の終わりまで）。その先は暗く表示します。
  - 札をドラッグすると小節の頭に吸着して動きます（下のトラックの END の札・線でも）。最後のチップより前にはできません。ダブルクリックで原曲の鳴り終わりに合わせます。編集メニュー（札の右クリックのメニューにもあります）の「曲の終わり（END）を ▶ の所にする」「END を最後のチップのすぐ後にする」でも決められます。
  - 決めていなければ、原曲の鳴り終わり（ほぼ無音の末尾は数えない）の次の小節の頭です。参照映像（YouTube）の長さは、原曲のファイルが無いときだけ使います（MV やライブは前後が長いので）。
  - 最後のチップより後まで続けるときは、終わりの1つ前の小節の頭に、表示を変えない「小節線・拍線の表示（C2）」のチップを書いて DTXMania でも同じ所まで続けます。読み込むとこの印は外して END に戻します。印の無い譜面は、DTXMania と同じく最後のチップの次の小節線を END にします（保存しても変わりません）。最後の小節線を消す C2 の飾りは END と一緒に動きます。

## DTXMania の曲（PC）

PC の Chrome・Edge で、DTXMania のゲームのフォルダ（.exe のある所）か DTXFiles を覚えて、ゲームに入っている曲を一覧から開いて直せます（フォルダを覚えられない iPad・スマホ・Safari・Firefox では出しません）。

- 始め方: ホームの「DTXMania の曲をまとめて扱う」の「DTXMania のフォルダを選ぶ…」か、ファイルメニューの「DTXMania の曲…」。選んだフォルダはこのブラウザに覚え、次からはホームのカードに曲と譜面の数・最近変わった曲（押すと開く）・探す欄・しぼりこみの入口が出ます。
  - Chrome が「毎回許可する」を覚えていないときは、前回の一覧を出しておき、曲を開く・読み直すときに読み書きの許可を 1 回聞きます。
  - 一覧の上の「曲のある場所」で、別のフォルダを選ぶ・DTXPath にある外の場所を選ぶ・このフォルダを忘れる（一覧と小さい画像をこのブラウザから消すだけで、ファイルは消えません）ができます。
- 探し方は DTXMania と同じ決まりです。
  - set.def のあるフォルダは、#TITLE ごとに 1 曲で、#L1〜#L5 が難易度です（書いてあるのにフォルダに無い譜面の難易度は、DTXMania と同じく出しません）。
  - set.def の無いフォルダは、DTXMania は譜面 1 つずつを別の曲にしますが、一覧ではフォルダで 1 曲にまとめます（譜面が 2 つ以上なら点検に出します）。
  - box.def のあるフォルダと、名前が「DTXFiles.」で始まるフォルダは BOX です。ほかのフォルダは素通りなので、曲名のフォルダが二重になっていても中の曲を読みます。set.def のあるフォルダの下も探します。
  - ゲームのフォルダを選ぶと Config.ini の DTXPath を読みます。選んだフォルダの外にある場所は、そのフォルダを選ぶと続けて読みます。
  - 一覧に読むのは名前と小さいファイル（set.def・box.def・譜面の頭・*.score.ini・画像）だけで、音や動画は読みません（音は、曲を選んだときにその曲の BGM だけ聞きます。下の「BGM をドラム抜きに」）。一覧と小さい画像（#PREIMAGE、無ければ #STAGEFILE）はこのブラウザ（IndexedDB）に控え、次に開くとすぐ出して、裏で変わった譜面だけ読み直します。「読み直す」は DTXMania の「Reload Songs」と同じく全部を読み直します（読んだ曲から並び、止めても読んだ所までは残ります）。
- 一覧: 1 曲 1 行で、画像・曲名・アーティスト・BPM・4 つの難易度（BASIC〜MASTER）のレベル・印（エディタで直した・AI で作った難易度がある・Google Drive にも保存している・保存していない続きがある・BGM にドラムが入っている・点検）を並べます。
  - 左で BOX（と BOX の外）ごとにしぼりこめます。しぼりこみは、難易度が足りない・BGM にドラム入り・エディタで直した・AI で作った難易度あり・Google Drive にある・保存していない続き・点検のある曲。並べ替えは、更新日・曲名・アーティスト・BPM・レベル・点検の多い順。曲名・アーティスト・フォルダの名前で探せます。
  - キー: ↑ ↓ で選ぶ、Enter で開く、Space で試聴、/ で探す。
- 曲を選ぶと、右に詳しい所が出ます: 大きい画像と試聴、難易度とレベルとあなたの成績（DTXMania の *.score.ini。遊んだ難易度だけ）、点検、フォルダ、エディタ（直したか・保存していない続き）、Google Drive。
  - 「開く」でいちばん上の難易度を、難易度の枠を押すとその難易度をエディタで開きます（保存していない続きがあれば続きから）。「曲情報」で曲情報の画面を開きます。
  - 空いた難易度は「AI で作る」で、その曲の AI難易度生成を開きます。
  - あいだに作る: 遊びたいレベルの譜面が無い曲は、詳しい所の「あいだに作る」にレベルを入れると、どの難易度に作り、どの譜面を移すかと、作ったあとの並びが出ます（前に入れたレベルがはじめから入っています。その曲で作れなければ、いちばん広いあいだの真ん中）。あいだに空いた難易度があればそこに作り、無ければ曲にある譜面を下の難易度へ 1 つずつ移して空けます（例: ADVANCED 5.10・EXTREME 7.50・MASTER 8.40 で 6.5 なら、5.10 を BASIC に移して、空いた ADVANCED に EXTREME から作る）。「AI難易度生成で ○○ を作る」で、作る元の譜面（すぐ上の譜面）を開き、移した状態で AI難易度生成が開きます。新しい譜面は上の譜面を間引いて作るので、作れるのはいちばん上の譜面より 0.3 以上低いレベルだけで、ほかの譜面とも 0.3 以上離します。出すのは、譜面が 2 つ以上あって、いちばん上より下に空いた難易度がある曲だけです。移し方と反映は、下の「AI機能」の「難易度を下へ移して、あいだに作る」と同じです。
  - BGM をドラム抜きに（ステム分解）: 曲を選ぶと、その曲の BGM（いちばん上の譜面の、いちばん初めの BGM チップの音。エディタの原曲と同じ）の 3 か所（25%・50%・75% の所から 12 秒ずつ）をドラムの採譜モデルで聞き、バスドラム・スネアが 1 分に 20 回以上ならドラム入りとして、詳しい所に「ステム分解」の案内を出します（エディタの「原曲にドラムが聞こえるか」と同じ数。名前がドラム抜きらしい BGM（_nodrums・_drumless・（ドラム抜き）など）は、聞かずにドラム抜きとします）。「ステム分解する」で、いちばん上の譜面をエディタで開き、ステムとミックスの画面の分解のカードで、ドラムとドラム抜きに分けて、ドラム抜きを BGM にします（分解のカードの「ドラム抜きを BGM に反映」と同じ。同じ BGM のほかの難易度も。元の BGM のファイルは残します。開いている譜面は、保存すると曲のフォルダに書きます）。もうステムのある曲は分け直さず、分解のカードを開くだけです。
    - 聞いた結果はこのブラウザに覚え、譜面と BGM のファイル（大きさ・更新時刻）が同じなら聞き直しません。詳しい所の「BGM」の行に、ドラム入り・ドラム抜き（1 分あたりの回数）・名前からドラム抜き・BGM が無いなどが出ます。
    - しぼりこみ「BGM にドラム入り」は、聞いた曲のうちドラム入りの曲です。まだ聞いていない曲は、しぼりこんだときの「まだの ○ 曲を調べる」でまとめて聞けます（1 曲 2 秒ほど。止められて、一覧の画面を離れるとやめます）。
    - 聞くのは、読み書きを許可していて、エディタの右のパネルの「ドラムの採譜モデルで打点を聞き取る」がオンのときだけです。音はブラウザの中で聞き、どこにも送りません。
  - エディタからはファイルメニューの「DTXMania の曲…」で一覧に戻れます（いまの譜面は自動保存の控えに残します）。一覧の「編集中の譜面に戻る」でエディタに戻ります。
- 点検（DTXMania で困る所）: 一覧を出したあとに、裏で 1 曲ずつ譜面を全部読んで調べます。
  - set.def が無い（譜面が 2 つ以上）: 「set.def を作る」で、中身を見せてから作ります（DTXMania で難易度が 1 曲にまとまります）。
  - set.def に書いた譜面が無い: その難易度は DTXMania に出ません。「set.def を直す」で、無い譜面の行だけを外します（ほかの行と文字コードはそのまま）。
  - 譜面が使うファイル（音・画像・動画）が無い・DTXMania で読めない名前（Shift_JIS で書けない文字）: 「開いて直す」でエディタで開きます。
  - 同じ曲が二重にある: DTXMania の選曲画面に 2 回並びます。消すのはエクスプローラーで（このアプリは消しません）。
  - 試聴が無い・画像が無い: 「曲情報を開く」で入れられます。ドラムの譜面が無い（ギター・ベースだけの曲）: 一覧に出すだけです。
- 書くのは、set.def を作る・直すとき（押して、中身を見せてから）と、保存したときだけです。DTXFiles や BOX の直下には書かず、曲のフォルダの中に書きます。
- 新しい曲を DTXMania の曲に保存する: DTXMania の曲を覚えていると、まだ曲のフォルダの無い曲（新しい曲・ブラウザの中だけの曲）を保存するときと、ファイルメニューの「曲フォルダに書き出す…」で、場所を聞く画面が出ます。
  - 「DTXMania の曲に入れる（おすすめ）」で、入れる所（もうある BOX・＋ 新しい BOX…・BOX の外）と曲のフォルダの名前（初めは曲名から）を選びます。書くフォルダとファイルを見せてから保存します。前に入れた BOX を覚えます。
  - 新しい BOX は、BOX の外の場所にその名前のフォルダと box.def（`#TITLE 名前`、Shift_JIS）を作ります。BOX の外は、ゲームのフォルダを選んだときは DTXFiles の中です。
  - 保存すると、その曲が一覧にも入ります。DTXMania を開いたままなら、DTXMania の設定の「Reload Songs」で選曲画面に出ます。
  - ほかに、「別のフォルダを選ぶ…」（今まで通り、選んだフォルダの中に曲のフォルダを作る）と「このブラウザの中に保存」も選べます。
- Google Drive とのかかわり（曲ごと・保存したときだけ。下の「PC どうしの同期」を始めると、合わせる曲は開いたとき・5 分ごとにも合わせます）:
  - 一覧の読み込みでも、曲を開いただけでも、何も送りません。送るのは保存した曲の、その曲のフォルダだけです（ほかの曲・DTXFiles・BOX は送りません）。
  - 保存の画面の「保存したら、この曲のフォルダだけ Google Drive にも送る」を外すと、その曲は送らないことにします。詳しい所の Drive の行の「この曲は送らない」「送るようにする」でも変えられます（曲のフォルダの .dtxe-drive.json に印を書く・消す）。送らないことにした曲も、エディタのフッターの「Drive にも保存」を押せば送ります。
  - 初めて送る曲が 100 MB をこえるときは、送る前に聞きます（DTXMania の曲に限らず、どの曲でも）。選べるのは「動画を除いて送る（おすすめ）」（動画はこの PC の曲のフォルダに残り、ほかの機器では動画なしで開きます。次からも動画は送りません）・「全部送る」・「この曲は Drive に送らない」（次からも聞きません）・「あとで」。Drive の空きと、このアプリで送った曲の数と大きさも見せ、空きが足りない送り方は選べません。
- しくみ（開発）: `src/nxlib/`（探し方 `scan.ts`・点検 `check.ts`・一覧の状態と覚えたフォルダ `store.ts`・`db.ts`・保存の場所 `save.ts`・set.def を作る／直す `actions.ts`・BGM にドラムが入っているか `bgm.ts`・`bgmListen.ts`）、画面は `src/ui/nxlib/`、100 MB の確認は `src/ui/DriveFirstDialog.tsx`。

## PC どうしの同期（Google Drive）

譜面を作る PC と、ドラムで DTXMania を遊ぶ PC が別のときに、同じ Google アカウントの Drive を通して曲と成績を合わせます（v0.54.0〜。PC の Chrome・Edge で、上の「DTXMania の曲」を覚えている PC どうし）。作る PC で直した曲は遊ぶ PC の DTXMania へ、遊ぶ PC の成績は作る PC へ届きます。どちらの PC でも作れて遊べます。

- 始め方: 「DTXMania の曲」の左の「PC どうしの同期」の「はじめる…」か、ホームの DTXMania の曲のカードの「PC どうしの同期…」、設定の Google Drive の「PC どうしの同期」。2 台目の PC でも同じ所から始めます。
  1. この PC の名前（作るPC・遊ぶPC など。記録と知らせに出すだけです）。
  2. 合わせる曲: 「作った曲（おすすめ）」は、このアプリで直した・保存した曲と、あとから足した曲・BOX です。これから作る曲も、保存すると入ります。「全部の曲」は DTXMania の曲を全部です。
     - 「全部の曲」を選ぶと、大きさと Drive の空きを比べる画面が出ます。無料の Google Drive は 15 GB で、Gmail・Google フォトと共有です。いっぱいになるとメールの送り受けや写真の保存も止まるので、入らないときは選べません（「作った曲だけにする」「BOX を選んで足す…」「動画を除いて全部」を選べます）。入っても空きの半分より多く使うとき、はじめの送信に時間がかかるときも知らせます。
  3. 一緒に合わせるもの: 成績とゴースト（DTXMania が書く *.score.ini・*.ghost）、動画（BGA）も送る、同期しない曲も成績だけ合わせる（初めは切）。
  4. Google Drive の空きと、この同期で使う大きさ。
  5. いつ合わせるか: アプリを開いたとき・開いている間は 5 分ごと・曲を保存したとき（その曲だけすぐ）・「今すぐ同期」を押したとき。
- 初めての同期: 「次へ：何が起きるか見る」で、この PC の曲と Drive の曲を比べ、取る・送る・まとめる・新しい方にする・確かめてほしいことを、始める前に曲ごとに見せます（まだ何も書き換えません）。「同期を始める」で始めます。
  - 両方の PC の同じ場所に同じ曲があれば、1 つの曲として合わせます（前に USB などで写した曲も）。場所が違って曲名とアーティストが同じなら、同じ曲か聞きます。
  - この PC の版がほかの PC の譜面を置きかえるときは、どちらにするか聞きます。
- 合わせ方（ファイルごと。前の同期からの変わり方で決めます）:
  - 作るファイル（譜面・音・画像・set.def・box.def・作業ファイル）と、遊ぶファイル（*.score.ini・*.ghost）は別のファイルです。作ると遊ぶが同期しないまま同時に進んでも、譜面は直した PC から、成績は遊んだ PC から届き、聞かずに合わせます。
  - 両方の PC で遊んだ成績は 1 つにまとめます。いい記録（ハイスコア・スキル・ランク）は良い方、遊んだ回数は両方で増えた分を足します（初めて合わせるときは、同じ回を 2 回数えないように多い方）。ゴーストはいい記録の方から取ります。
  - 両方の PC で同じ譜面・音を直していたら、新しく直した方を残し、もう一方は Drive の「DTX Web Editor/控え」に 30 日残します（ほかの PC には取りません）。同期の記録の「…の版に戻す」で戻せます（どちらの PC もその版になります）。PC の時計がずれているときは、決めずに聞きます。
  - この PC で消したファイルは、Drive ではゴミ箱へ移し（30 日は戻せます）、ほかの PC でも消します（そこで直していたら残します）。一度にたくさん消えていたときは、消さずに戻します。成績は消しません。曲のフォルダごと消したときは、ほかの PC でも消すか聞きます。
  - DTXMania は開いたままで大丈夫です。遊んでいる曲のファイルが書けないときは、次の同期で合わせます。取った曲は、DTXMania の Config → System の「Fast Reload」か、DTXMania を開き直すと出ます。
  - エディタで開いている曲には、ほかの PC で直した譜面を勝手に書かず、「取り込む」を勧めます（成績は合わせます）。
- Drive の置き方: 「DTX Web Editor/DTXFiles/<BOX>/<曲のフォルダ>」で、DTXMania の曲と同じ並びです。この PC に無い曲は、同じ BOX に取ります。iPad などで作って「DTX Web Editor」の直下にある曲は、設定で選んだ BOX に取り、Drive でもその BOX へ動かします。
- 見る所:
  - 上の「同期しました · 2 分前」の印（押すと同期の記録）と、ホームの帯（何を取った・送ったか、両方で直したファイル、確かめてほしいこと、ログインが切れたとき）。
  - 「DTXMania の曲」の一覧の印（同期・成績 +3・まとめた・新しい曲）と、しぼりこみ「同期する曲」「同期で変わった曲」。ホームのカードには、同期で変わった曲が並びます。
  - 曲の詳しい所の「同期」: この曲を合わせる・外す、作るファイルと遊ぶファイルの前の同期。
  - 同期の記録（この PC に 30 日）: 1 回ごとに、取った・送った・まとめた・控えにした物と、確かめてほしいことへの答え。

## 耳コピアシスト

原曲を聴きながら、波形と打点を見て耳コピするための機能です。

- **聴く**
  - ループ再生: 上のバーの「ループ」（/）で ▶ の小節を、譜面の左端の帯・下のトラックの上の帯・全体図の帯のドラッグで好きな範囲をループします。上のバーの A・B（I・O キー）で今の位置を始まりと終わりに1つずつ決めることもできます（A だけの間はループせず、B も決めたときにループします）。
  - スロー再生: 25%・50%・75%。曲の音（原曲・SE・ステム）は音程を変えずに遅くし（ワーカーで伸ばした音を順に鳴らします）、チップの音（ドラム）は叩いた音のまま遅くした時刻に鳴らします。原曲のドラムなどを SE（61〜92 ch）で鳴らす譜面も、原曲とずれません。
  - 原曲を聴く帯域: 全体・低域（キック）・中域（スネア・タム）・高域（ハイハット・シンバル）を選べます。
  - レーンごとのミュート（M）とソロ（S）があります。
- **見る**
  - 譜面の右に「原曲の打点」と「原曲の波形」の列を出します。波形の見出しを押すとスペクトログラムに切り替わります。
  - 原曲の打点は、ドラムの採譜モデル（下の「ドラムの採譜」）が聞き取った5種（BD・SD・タム・HH・シンバル）の打点です。採譜が終わるまでと、右パネルで採譜を切っているときは、原曲を低・中・高の3帯域に分けた打点を出します。
  - 打点とスペクトルは、譜面のチップと同じ時刻の物差しで描きます（正解つきの曲で測ると、採譜の打点は ±1ms、スペクトルの立ち上がりは ±5ms。スペクトルの明るい所は音の伸びの分だけ少し後ろに出ます。[測った結果](bench.md#表示の時刻譜面のチップとのずれ)）。打点がチップより揃って前後にずれて見えるときは、開始位置（BGM チップの位置）か BPM がずれています。
  - ずれは自動で測ります。チップと採譜の打点が 12ms 以上ずれていると、「原曲の打点」の見出しが「ずれ +24ms」のように黄色になり、押すと開始位置のずれか BPM の違いか（テンポの揺れか）の見立てと、1クリックで直すボタンが出ます（BGM のチップを動かす・BPM を直す。Ctrl+Z で戻せます）。打点をステムから取っているときは、ステムと原曲のずれも測り、ステムがずれていれば「ステム +25ms」と出して、ステムの頭のずれを直せます（分離ソフトによっては MP3 の頭の無音を足したまま書き出すため）。[測った結果](bench.md#ずれの自動チェック譜面と原曲の打点ステムと原曲)
- **ドラムの採譜**（右パネルの「ドラムの採譜モデルで打点を聞き取る」でオン・オフ。既定はオン）
  - 原曲（解析元に選んだ音）から、ドラムの5種の打点をブラウザの中で聞き取ります。音はブラウザの外に出しません。4分の曲で十数秒かかり、一度採譜した曲はブラウザに覚えておくので次からはすぐ出ます。
  - モデルは [ADTOF](https://github.com/MZehren/ADTOF)（M. Zehren, M. Alunno, P. Bientinesi）の Frame_RNN を ONNX にしたもの（[thebluescreen/adtof-drums-onnx](https://huggingface.co/thebluescreen/adtof-drums-onnx)、2.2MB、ライセンス CC BY-NC-SA 4.0）。リポジトリには入れず、初回だけ Hugging Face から読み込みます（版を固定し、SHA-256 を確かめます）。動かすのは onnxruntime-web（WASM、初回に約4MB）です。モデルのライセンスは非商用に限るので、商用で使うときは採譜を切ってください。
  - 精度（手元の曲、±50ms）: 本物のドラムの録音入りで F 0.68、原曲そのもので 0.76、ドラムの無い音では 0.02（ほとんど何も出さない）。タムの高さや左右のシンバル・ライドは区別しません。
  - 聞き取った打点は、TAB補完の候補選び・オレンジの枠、AI のフレーズ候補に渡す原曲の打点にも使います。
  - 画面下のトラックの上の帯にセクションとループの範囲、トラックごとに原曲・ステムの波形と譜面の音（レーンの色の印）を出します。
- **TAB補完**（右パネルの「TAB補完」でオン・オフ）
  - チップを置くと、その先の空いた小節（1〜4小節、設定で変えられます）に続きを点線で出します。コードエディタの補完と同じで、`Tab` でまとめて入れ、`Shift+Tab` で1小節だけ入れ、`Esc` で消します。`Alt+]`・`Alt+[` で候補を切り替え、点線が出ていないときはカーソルの所に呼び出します（ツール › TAB補完 も同じ）。
  - 候補はこの曲でもう打った小節を写して作ります。直前の数小節と同じ並びの所の続きと、原曲で同じに聞こえる小節（2番のサビ＝1番のサビ など）を探し、「次の小節がそのまま正解になる見込み」が高いものだけを出します（出す量：控えめ・ふつう・多め）。ドラムの採譜ができていれば、原曲で聞こえるバスドラム・スネア・タムに合う候補を選びます。打つほど当たるようになります。
  - 点線の上の札に、写した元・見込み・候補の数を出します。写す元が無い変わり目は「AIに聞く」で AI に続きを作ってもらえます（フレーズ候補のモデル。キーが要ります）。
  - 原曲でその音が聞こえない点線のバスドラム・スネア・タムは、オレンジの枠で示します（外れのことが多い所。採譜ができていないときはスネアだけ）。
  - 精度（手元の6曲23譜面、ふつう、採譜あり）: 点線は2小節に1回ほど出て、出した小節の 57% がそのまま正解、チップの F 値 0.93。[耳コピ精度テスト](#耳コピ精度テスト) で測れます。
- 原曲を3帯域に分けて打点を振り分けるだけの「候補チップ」は精度が足りなかったので外しました（2026-11）。代わりに、ドラムの採譜モデルの打点を出しています。
- **小節の生成（✨）**（譜面の左端、小節線ごとの ✨。Alt+G・ツール › ▶ の小節をAIで生成・右パネルの「小節」でも）
  - ✨ を押すと、その上の小節の案を点線で出します。AI を呼ぶのは押したときだけです。Shift+クリックで範囲を広げます（4小節まで）。
  - 案は3種類で、Tab で切り替えます。「AI」は AI に作ってもらう案で、3つ出します（キーが要ります。「ひとこと」で注文を付けて作り直せます）。「写す」はこの曲でもう打った小節を写す案（TAB補完と同じ選び方）。「採譜」は採譜モデルが聞き取った打点をそのままチップにした案で、ライドかシンバルか・HHの開け閉め・タムの高さ・スネアかリムか（採譜はリムを聞き分けないので、作者がその位置をリムで書いているか）は前後の小節の書き方に合わせます。
  - スネアのリムは、AI には格子の RM の行として渡し、譜面のリムはリム、スネアはスネアのまま書くように頼みます（入れ替えない）。写す案・TAB補完・フレーズ候補・AI難易度生成でも、リムはリムの音のままです。
  - AI は曲を聴けないので、耳コピする人が見ているもの（ドラムの採譜の確からしさと、ドラム強調のスペクトルの帯の明るさ）を、譜面と同じ拍ごとの格子の 0〜9 の数字にして渡します。あわせて作者が書いた小節（手本）の「分析と譜面の組」を見せ、作者が分析をどう譜面にしているか（シンバルの8分をライドの4分で書く、聞こえない左足を足す など）をつかんでから書かせます。手本は、分析が近い作者の小節・写す案の元・すぐ前の小節から選び、手本から数えた「読み方の目安」（採譜が強い所に作者が書いたレーンの割合）も渡します。分析が手本とほぼ同じなら、その手本をそのまま使って違う所だけ直させます。手本を土台にした案は、札に「小節 ○○ が土台」と出します。
  - 自動で入れた小節（TAB補完・✨・フレーズ候補・似た小節へのまとめての反映で入れて、まだ手で直していない小節）は、手本にも前後の小節の譜面にも書き方の要約にも使いません（自動で入れたものを作者の書き方と取り違えないため。分析だけ渡します）。手で直すと作者の小節になります。フレーズ候補・AIに聞くでも同じです。
  - 入れ方（マージ）: チップがもうある小節では「足す」（いまのチップは残して、無いものだけ足す）と「置き換え」（案に無いチップは消す）を選べます。レーンごとに入れる・入れないを切り替えられ、点線のチップをクリックすると外し、置き換えで消える赤い × のチップをクリックすると残します。手が3本いる・同じ足が2つになる組み合わせは入れません。原曲で聞こえないバスドラム・スネア・タムはオレンジの枠で示します。
  - Enter で入れ、Shift+Enter（札の「入れて次へ」）で入れて次の小節へ、Esc でやめます。次の小節が譜面の外なら、点線の案が見える所まで送ります（Alt+G で ▶ の小節を開いたときも。再生中は動かしません）。入れたものは Ctrl+Z 1回で戻せます。開いている間に再生すると、案を入れた音で鳴ります。
  - 案は当たりそうな順に並べます。形がはっきり同じ小節があれば「写す」、無ければ「AI」を先に出します。
  - 置く位置は設定のグリッドに縛られません。「AI」と「採譜」は拍ごとに 16分・8分3連・16分3連・32分 のうち原曲の打点の時刻にいちばん合う細かさを選び、3連や32分のフィルもその位置に置きます（打点1つの時刻のぶれでは3連にしません）。「写す」は元の小節の位置のまま写します。
  - 精度（Bless your breath の MASTER を前から順に書く想定で、隠した17小節を当てる。作者の譜面とのチップの F 値）: 写す 0.89、AI（GPT-6.1 Terra。既定）0.86、AI（GPT-6 Luna）0.74、採譜 0.62。キーなしで最初に出る案は 32 小節で 0.91。AI は1回 約 $0.004・約6秒です。
  - 原曲の分析と手本を渡す前と後の比べ（6曲の MASTER を前から順に書く想定で隠した48小節を2回ずつ。GPT-6.1 Terra）: AI の1つめの案の F 値 0.816 → 0.836、そのまま正解 18% → 25%、3つのうちいちばん近い案 0.850 → 0.879、前に同じ小節が無い形（フィルなど）は 0.731 → 0.768。並べた案の1つめ（形がはっきり同じ写す案が先）は 0.826 → 0.848、そのまま正解 29% → 37%。1回 約 $0.002〜0.005・約6秒（スペクトルの帯は初めての ✨ で作り、3分の曲で2秒ほど）。
  - ドラム抜きの BGM（採譜でバスドラム・スネアがほとんど聞こえない）では、採譜の案と原曲との照合は出さず、写す案と AI の案は前後の流れから作ります。
- **テンポ合わせ**（上のバーの「BPM・拍子」、または ツール › テンポと開始位置を合わせる）
  - 原曲のBPMを推定し、倍・半分の候補とタップでの計測も出します。
  - 新しい譜面（ドラムがまだ無い）では、推定から 1 小節目の頭まで決めた案を作ります。倍・半分と 1 拍目は、曲全体の打点をよくあるドラムの形（キックが 1・3 拍目、スネアが 2・4 拍目、1 拍目にシンバル）に重ねて、いちばん合うものを選びます。1 拍目と 3 拍目は形だけではほとんど差が出ないので、和音とベースの音が変わる拍でも確かめます（和音もベースも小節の頭で変わりやすいので、前の 1 小節と後の 1 小節がいちばん違う拍を 1 拍目にします。曲の音から測るので、案が少し遅れて動くことがあります）。テスト曲 6 曲と README のデモ曲では BPM・1 小節目の頭とも作者の譜面と合いました（ずれは 13ms 以内。前の版は BPM 5 曲・頭 3 曲）。
  - 1小節目の頭を波形の上で決めると、BGMチップ（ch01）の位置を DTXMania の分解能（1小節 = 384）で計算します。
  - 小節線をドラッグしてアンカーを置くと、アンカーの間のBPMを計算して小節の頭でBPMを変えます。
  - 確認再生（クリック付き）で合っているか聴けます。「譜面に反映」は Ctrl+Z で戻せます。
- **BPMタップ**（上のバーの「BPMタップ」、T キー、または ツール › 曲に合わせてクリックでBPMを測る）
  - 曲に合わせて拍をクリック（T キー）すると、4回目からBPMが出ます。叩き損ねて拍が飛んでも数え直します。
  - 再生しながら叩くと、BPMと一緒に小節の頭も合わせられます（原曲があれば BGM チップの位置、YouTube だけなら映像のずれを動かします）。最初に叩いたのが何拍目かを選べます。
  - 止まったまま叩いたときは BPM だけ反映できます。
- 譜面が空でも、原曲や YouTube の長さぶん再生・スクロールできます。原曲も映像も無いときは止めるまで流れます。
- **置く**
  - 入力の「キー」: A S Z D G F H J K L（LC HH LP SD HT BD LT FT CY RD）でカーソル位置に置きます。Shift で HHオープン・左バスドラム・スネアのリムです。もう一度押すと消えます。
  - 入力の「録音」: 再生しながらキーボードや電子ドラム（Web MIDI）で叩くと、グリッドに吸着して置きます。ループ中は周回ごとに重ねて録れて、1回の再生ぶんを Ctrl+Z でまとめて戻せます。
  - 設定画面（右上の歯車）で、電子ドラムのノート割り当て（覚える）、ハイハットの開閉の判定（ノート番号／ペダル CC4）、強さの無視、キーの割り当て、入力の遅れの補正（測定つき）を変えられます。電子ドラムのノート 37（GM の Side Stick、Roland の XStick）ははじめからスネアのリムです（40 のリムショットはスネアの強打なのでスネア）。
  - Ctrl+D で前の小節をカーソルの小節に複製します。
- **そのほか**
  - YouTube の参照映像を、譜面の再生に合わせて動かせます（ずれの調整つき。音は原曲ファイルが基本で、原曲ファイルが無ければ YouTube の音を鳴らします）。
  - 原曲とのずれは自動で合わせます（Chrome・Edge）。動画を読み込むと、ブラウザの「このタブを共有」でタブの音を受け取り、YouTube の何か所かを 8 秒ずつ聞いて原曲と比べます。比べるのは打点・音色・和音の特徴なので、MV の前置きのセリフや効果音、音質の違いがあっても曲の所どうしで合わせます。ずれは曲の最初で合わせたものが基本です。所ごとに変えるのは、2 か所以上の聞き取りがそろって元のずれでは全く合わないとき（途中を切ったゲームサイズ・MV の編集）と、ずれが一方向へなめらかに少しずつ変わるとき（テンポが少し違うライブ版）だけです。途中を切った版では、切れ目の近くを何か所か聞き足して、2 秒の窓で所ごとに比べ、前のずれで合わなくなって後のずれで合い始める所で切り替えます（最後に 0.5 秒の窓で詰め、ずれは 0.2 秒ほどまで）。ドラムだけの所や効果音で一瞬似なくなったのを切れ目と取り違えないよう、切れ目の手前を前のずれで、先を後のずれで聞いて確かめます。切れ目は今のところ 1 か所まで（2 か所以上切った版では、1 つの区間がずれたままになることがあります）。1 か所だけ曲の別の所（2 回目のサビなど）に似たときは、ずれは変えず、近くを聞き直して確かめます。「一定にする」で、所ごとの差をやめて最初のずれのままにもできます。タブの音が手元に届くまでの遅れは小さなクリックで測ります。合わせ直す・元に戻す・± で直すこともできます。サーバーは使いません。
  - 小節番号をダブルクリックすると、セクション（Aメロ・サビなど）を付けられます。
  - 小節を直すと、直す前に同じパターンだった小節を覚えておき、右パネルからまとめて反映できます。
  - セクション・YouTube・テンポのアンカー・自動で入れた小節の印は、DTX と同じフォルダの作業ファイル（`<譜面名>.dtxe.json`）に保存します。DTXMania はこのファイルを読みません。

## 強さ・音量ミキサー・ステム

- **強さ（ベロシティ）**
  - DTX には音ごとの強さが無いので、「チップの強さ = その WAV の #VOLUME」として扱います。強さを変えると、同じファイルで #VOLUME だけ違う WAV 番号（強さ違い）に付け替え、無ければ `#WAVzz`・`#VOLUMEzz` を足します。譜面はいつでもそのまま DTXMania で遊べます。
  - 置く強さは上のバーの「強 / 中 / 弱」（1・2・3 キー、初期値 100・70・35）。Alt+クリックで弱く置けます。電子ドラムは叩いた強さで置きます（設定で強さのカーブを選べます）。
  - 選んだチップは Alt+ホイール・Alt+↑↓ で ±5（Shift で ±1）。右パネルにも強さのスライダーがあります。
  - V キー（または上のバーの「強さの編集」）で強さの編集モード。譜面の右に強さのレーンを出し、選択・鉛筆・直線（クレッシェンド）で変えられます。右パネルでまとめて変える（±5・そろえる・倍率・幅を詰める・ゆらぎ）、拍の位置で強弱、原曲の打点から決める（点線で見てから採用）が使えます。
  - 強さの刻み（5・10・1）とプリセットの値は設定画面で変えられます。
- **トラック**（画面下。DTM の音声トラックのように1本ずつ並べます）
  - 譜面の音・原曲・ステム（ドラム・ベース…）が1本ずつのトラックになり、それぞれにミュート（M）・ソロ（S）・音量があります。ソロはトラックをまたいで効き、S を Alt+クリックするとそのトラックだけにします。
  - 譜面が SE のチャンネル（61〜92）で音を鳴らしているとき（原曲のドラム drums.ogg を SE で重ねる譜面など）は「SE」のトラックも出し、SE だけを消したり下げたりできます。
  - 原曲・ステムのトラックの「スペクトル」にチェックを入れると、譜面の右の列にそのトラックのスペクトルを出します（外すと波形に戻ります）。◉ は解析元（波形・原曲の打点・BPM推定に使う音）です。
  - 「＋ステム」でステムを足せます。初めてステムを入れると、原曲のトラックはステムと重なるのでミュートにします（M で鳴らし分けられます）。ステムの名前と種類は、トラックにマウスを乗せると出る ✎ で変えられます。
  - 上の帯はループ（A–B）とセクション。トラックの上をクリックで再生を始める位置、A・B の線のドラッグでループの端を動かせます。上の境目のドラッグで高さ、▾ で開け閉めします。
  - 高さは「閉じる（上の帯だけ）・1本・細く（全部を1行ずつ）・標準（名前の下にファイル名）・ゆったり（波形を大きく）」で止まります。境目をドラッグすると近づいた高さに吸い付き（Alt を押しながらなら自由な高さ）、境目か角の右クリックのメニューでも選べます。境目を選んで ↑↓ キーでも1段ずつ変わります。細く・標準・ゆったりはトラックの数に合わせた高さなので、ステムを足すとそれに合わせて伸びます。トラックは半端な高さで切れず、全部が入らないときはスクロール（ホイールで1本ずつ）します。幅の狭い画面では、見出しの音量の数字を隠し、スペクトルは図だけの切り替えにして詰めます。
- **マスター**（上のバーの右）
  - 全体の音量とミュート、クリックの入り切り、ミックスのパネル。マスターの音量はこのブラウザに覚えます。
  - ミックスのパネルで、聞こえ方のプリセット（全部／ゲームと同じ／ドラムだけ／聴き比べ）、曲の音（原曲・SE・ステム）と譜面の音をまとめて消す（Alt+1・Alt+2）、レーンごとのミュート（Alt+押すとソロ。タブレット・スマホは長押しでソロ）、クリックの音量と「小節の頭だけ」を変えられます。
  - トラックとミックスの音量は聴くためのもので、DTX の #VOLUME や書き出しには影響しません。曲ごとに作業ファイルへ覚えます。
- **ステム音源**（ツール › ステムとミックス）
  - ステム分離ソフトで分けたファイルをまとめてドロップすると、ファイル名から種類（ドラム・ベース・ボーカル・ギター・ピアノ・その他）と名前を決めて、曲フォルダの `stems/` にコピーします。新規作成で音声ファイルを複数落としたときは、おまかせで準備の画面でステムとして扱います（「自分で入れる」でも、選んだ種類のまま読み込みます）。
  - ファイル名は drums・Drums・ドラム・ﾄﾞﾗﾑ・Dr・BassDrum・Kick・Vo・Gt・Keys・弦楽器 などいろいろな書き方に合わせます。まとめて読み込んだときは、どのファイルにも付いている部分（曲名・`_mixed` など）を除いた残りを名前にします（`back number - 水平線_弦楽器_mixed.mp3` → 弦楽器）。「ドラム抜き」「(No Drums)」はドラムにしません。
  - 名前と種類は、トラックの ✎（名前のダブルクリック・右クリックでも）で変えられます。種類は色と、聞こえ方のプリセット・BGM用（ドラム抜き）の書き出しに使うので、ドラムの音が入ったトラックは「ドラム」にします。前の版で「その他」になっていたステムは、作業ファイルを開いたときにファイル名から付け直します。
  - トラックごとにミュート・ソロ・音量・パン・頭のずれ（ミリ秒）。ステムは BGM チップ（ch01）の位置から鳴らします。ステムの合計 = 原曲なので、ステムがあるときは原曲のトラックを初めミュートにします。
  - 解析（波形・原曲の打点・BPM推定・強さの推定）に使うトラックを選べます。ドラムのステムがあれば初期値はドラムです。
  - 書き出し: BGM用（ドラム抜き、初期値）・全部を1本に・選んだステムを1本に・1本ずつ。OGG Vorbis（品質6）か WAV 16bit、ピーク −1 dB にそろえます。BGM用は BGM の WAV に、全部を1本には #PREVIEW に登録できます。元の原曲ファイルは上書きしません（`_drumless` を付けた名前にします）。
- **ステム分解**（ツール › ステムとミックスの「原曲から分解」。原曲カードの「ステムに分解」、トラックの「分解」からも開けます）
  - 原曲をブラウザの中で、**ドラム**と**ドラム抜き**（原曲からドラムを引いた音。足すと原曲にぴったり戻る）の2本、または楽器ごと（4〜6本）に分け、曲フォルダの `stems/` に OGG で置いてステムのトラックにします。音はどこにも送りません。ドラムのステムは原曲の打点（採譜）にも使います。
  - 「ドラム抜きを BGM にする」で、ドラム抜きを `<原曲の名前>_drumless.ogg` に書き出して BGM（#WAV）に登録します。音量は原曲のまま、元の原曲ファイルは残します。DTXMania では譜面のドラム音が鳴るので、遊ぶときの BGM はドラム抜きが基本です。音量をそろえるなど細かく決めるときは、右の「書き出し」の BGM用（ドラム抜き）を使います。
  - 分ける音は初め BGM です。BGM がドラム抜き（`_drumless`・`(No Drums)` など）なら、同じ名前の元の原曲を選びます。曲フォルダのほかの長い音声ファイルも選べます。
  - ステムに分ける前の完全な原曲（ドラム入り）は作業ファイルに覚えておき、BGM をドラム抜きにしたあとも、分け直す元（「完全な原曲」と出ます）・試聴に使います。書き出しで上書きしません。分けたステムは、まだ保存していなくても、リロード・難易度の切り替えのあとに自動保存の控えから読み直します。
  - モデルは [unblend](https://github.com/Ryan5453/unblend)（R. Fahey）がブラウザ用に ONNX にしたものです。版を固定して Hugging Face から初回だけ読み込み、SHA-256 を確かめてブラウザに保存します（カードの「消す」で消せます）。

    | モデル | 分ける種類 | 読み込む大きさ（fp16 / fp32） | 動く所 | ドラムの SDR（MUSDB18、30曲） |
    | --- | --- | --- | --- | --- |
    | BS-RoFormer SW（jarredou。既定） | 6種（ドラム・ベース・ボーカル・ギター・ピアノ・その他） | 335MB / 668MB | WebGPU | 12.1 dB |
    | SCNet XL | 4種（ドラム・ベース・ボーカル・その他） | 110MB / 211MB | WebGPU | 11.2 dB |
    | SCNet small | 4種 | 26MB / 46MB | WebGPU・CPU | 10.0 dB |

  - GPU は WebGPU（Chrome・Edge）で使い、fp16 を計算できる GPU では fp16 のファイルを読みます（unblend の作者によると精度は fp32 と同じ）。WebGPU が無いブラウザでは SCNet small を CPU で動かします（遅く、開発用のサーバーでは 30 秒の曲に約1分40秒）。
  - 測り方と結果は [docs/bench.md](bench.md#ステム分解) にあります。モデルの重みには利用条件の明示がないので、非商用の個人利用として使ってください。

## 音源ライブラリと標準キット

- **標準キット**（左パネルのキットのタブ）
  - 28種類（v0.41.0 から）。ジャンルごと（スタンダード・ロック/メタル・ポップ/ファンク・ジャズ/アコースティック・エレクトロ/ダンス・ゲーム/シンセ）に並べています。

  - キットを選ぶと、これから置くチップにその音を使います。「置いてあるチップも替える」で、置いてあるチップの音も強さを保ったまま替えられます（Ctrl+Z で戻せます）。
  - どのキットにもスネアのリム（GM の 37 Side Stick）の音があり、キットのタブの「リム」の行で、リムに使う音をほかの音（曲の WAV・ライブラリ）に替えられます。リムのチップはスネアと別に音が替わります。
  - 譜面には `dtxweb_<キット>_<レーン>.wav` の名前で書き、保存するときに使った音だけを曲フォルダへ WAV で書き出します。
- **音源ライブラリ**（ツール › 音源ライブラリ、またはキットのタブの「ライブラリ」）
  - 「曲フォルダから取り込む」で、DTXManiaの曲フォルダ（親フォルダでも可）の譜面で使われている音を取り込みます。どのレーンで何回使われたかから楽器を自動で決め（ファイル名も参考にします）、中身が同じ音は1つにまとめます。8秒より長い音（BGM など）は取り込みません。
  - 曲ごとに、レーンで一番多く使われた音を組み合わせた「曲名キット」を作ります。キットとして選ぶと、その曲の音で譜面を書けます。
  - 「音声ごと取り込む」はブラウザ内（IndexedDB）に音をコピーします。「参照モード」は場所だけ覚えて、使うときに元のフォルダから読みます（Chrome・Edge）。
  - 楽器・出典・曲・タグ・お気に入り・名前で絞り込み、試聴、楽器の手直し、似た音（音の特徴が近い順）、今の譜面のレーンへの割り当てができます。キットのタブでは自分のキットを作り、レーンごとに音を選べます。
  - ライブラリの音は譜面に `lib_<元の名前>` で書き、保存するときに曲フォルダへ書き出します。他の曲から取り込んだ音を使ったときは、保存の案内に出典を出します（個人の曲づくりの範囲で使ってください）。
  - 「ZIPでバックアップ」「ZIPから戻す」で、ライブラリを丸ごと持ち運べます。

## 旧Creatorの残り機能と確かめる機能

- **編集**
  - グリッドに 5連（1/20・1/40）・7連（1/28）・1/96・1/192 を追加。「任意の分割…」で好きな細かさにできます。
  - 小節の挿入・削除（編集メニュー、右パネルの「小節」）。後ろのチップ・小節長・セクション・テンポのアンカーもずらし、消した小節の BPM 変化と BGM の開始は次の小節の頭に残します。拍子は「7/8」「13/16」のように自由に入れられます。
  - 元に戻すは無制限。上のバーの時計のボタンで履歴を一覧し、好きな時点へ戻れます。
  - 検索と置換（Ctrl+F、F3 で次へ）：レーン・HHO/LBD・種類（通常・不可視・音だけ）・WAV番号・小節の範囲で探し、譜面でハイライト。見つかったチップをまとめて別のレーンへ移す（音も移した先の音にできる）、WAV番号を替える、種類を変える、消す。小節の範囲で2つのレーンを丸ごと入れ替える、左右反転もできます。
  - レーンの並び（設定 › レーンの並び）：DTXMania のレーン表示に合わせて自由に並べ替えられます。DTX の中身は変わりません。
- **素材**
  - WAV リストにラベル（`#WAVzz: file ;ラベル` のコメント）と使用数を表示。使っていない WAV をまとめて整理できます。原曲（BGM レーンで鳴らす音）・SE レーンで鳴らす音には番号の下に「原曲」「SE」の印を、10秒より長い音には長さを出します。
  - 試聴の ▶（WAV リスト・キットのタブ・音源ライブラリ）は、鳴っている間は ■ になり、もう一度押すと止まります。鳴らすのは1つだけで、別の音の ▶・Esc・曲の再生・タブやページの切り替えでも止まります（原曲のような長い音を試聴しても止められます）。鳴っている間は行の下に進み具合を出します。
  - 「画像」タブで #BMP・#AVI を登録（曲フォルダの画像・動画から、まとめて登録も可）。譜面の右に BGA 列を出し、クリックでレイヤー1〜8・差し替え・動画（54・5A）のチップを置けます。列を広げると画像のサムネイルが出ます。
  - ヘッダの「直接編集」で、好きな DTX コマンドを書き足せます（旧Creatorの自由入力）。
  - BGM/SE 列にフィルイン区間（53）とフィルインの音（1F）も出します。
- **確かめる**
  - DTXMania風の落下プレビュー（P で右のパネル、Shift+P で全画面）。再生に合わせてチップが判定ラインへ落ち、背景に BGA を出します。止めているときはカーソルの位置を出します。
  - 無理な配置の警告：手が3本いる同時打ち、足が足りない同時打ち（左ペダルと左バスドラムの同時など）、HH の開閉の同時、同じ手足の速すぎる連打。右パネルの「確かめる」に一覧し、譜面の左端とチップに印を出します。
  - 推定レベル：平均と一番密な2秒の打数、最大同時打数、速い連打の割合、手の移動から機械的に出す目安です。「これにする」で #DLEVEL に書けます。

## AI機能

AI は [OpenRouter](https://openrouter.ai/) を使います。キーは「設定 › AI（OpenRouter）」で入れ、このブラウザにだけ保存します（保存しない選択もできます）。キーが無くても、AI 以外の部分（ルールでの簡略化、似た小節からの候補、ガイドラインの集計など）は使えます。

- **AIの設定**：処理ごと（曲情報・フレーズ候補・小節の生成・レベル判定・難易度生成の方針・ガイドラインの下書き）にモデルと推論の強さを選べます。モデルの一覧は OpenRouter から取り、処理に必要な機能（Web検索・JSON の出力・推論）で絞り込み、おすすめ・安い順・新しい順に並べます。予備のモデルも指定できます。1回の目安の料金、今日・今月の使用額とキーの残り上限、1回の上限（超えると確認）と月の上限を出します。
- **曲情報**（ツール › 曲情報）：ヘッダの項目をまとめて編集。「曲情報を調べる」は、原曲のファイル名・タグ（MP3 の ID3、OGG/FLAC の Vorbis コメント、M4A、WAV。日本語の Shift_JIS タグも読む）・曲の長さを手がかりに、小さな AI エージェントが自分で Web 検索・iTunes の検索・YouTube の確認を繰り返して、正式な曲名・アーティスト・ジャンル・年・コメント・パネル文の案と、公式の YouTube 動画（MV・音源・ライブ）とジャケットの候補を出します。経過は画面に出し、YouTube の URL とジャケットは道具で確かめたものだけを使います。「まとめて設定」で、項目・参照映像（公式動画）・#PREIMAGE（ジャケット）・#STAGEFILE と #BACKGROUND（動画のサムネイル）を一度に設定できます。キーが無くても、タグと iTunes から案を出します。音声ファイルから新しい譜面を作るときも、タグの曲名・アーティスト・BPM を最初から入れます。タグに BPM が無ければ、作る画面を開いている間に原曲から BPM を推定して入れ、半分・倍の候補も押して選べます（自分で入れた BPM は書き換えません。動画は作るときに音を取り出すので推定しません。拍の位置は「テンポ合わせ」で合わせます）。ジャケットは切り抜いて曲フォルダに PNG で保存します。
- **試聴をサビから作る**（曲情報 › 選曲画面 › プレビュー音の「サビから作る…」）：DTXMania は試聴（#PREVIEW）のファイルを頭から繰り返し鳴らすだけなので、曲のサビを探して、そこを切り出したファイル `preview_chorus.ogg` を作り、#PREVIEW に入れます。
  - 曲の音は、作業ファイルが覚えている完全な原曲（ドラム入り）、無ければゲームで鳴るとおりの BGM と長い SE（SE で鳴らすドラムのステムなど）、原曲がドラム抜きでステムを読み込んであればステムを全部足した音（ステムだけの曲）を使います。
  - 曲を小節ごとの和音・音色・ドラムの形で部分に分け、同じに聞こえる部分に同じ文字を付けます（帯に色で出し、サビは青）。分け方の細かさを変えて何通りも分け、それぞれ盛り上がり（明るさと音量）・繰り返しの数・長さでサビらしい所を選んで多数決し、前奏の後の最初のサビを出します。サビの頭は、小節の頭の叩かれ方・前の小節が 1 回きりのフィルか・サビのドラムの形が始まる所で小節単位に合わせ、2 回目からのサビは 1 回目と小節ごとに並ぶ所に合わせます。小節線は先に曲の打点に合わせるので、小節の頭が数十 ms ずれていても答えは変わりません。テスト曲 6 曲と README のデモ曲では、作者が作った試聴（サビの頭）と小節までぴったりでした（小節線を ±60ms ずらしても同じ）。小節は譜面の小節線を使い、譜面の拍が曲に合っていなければ曲の音から拍を追って推定します（テンポを合わせると正確になります）。
  - 候補（サビ・2 回目のサビ・ほかの候補）を押すか帯を押して所を選び、1 小節ずつずらし、長さ（4・8・12・16 小節。初めは約 15 秒）を選んで「試し聴き」で確かめます。「ここを試聴にする」で、小節の頭の少し前から切り出し、終わりは少し延ばしてフェードアウトした OGG を書き、#PREVIEW に入れます（同じ試聴だったほかの難易度にも。知らせの「元に戻す」で前の試聴に戻ります。完全な原曲や譜面で使っている音は上書きしません）。今の試聴は「聴く」で鳴らせます。
  - ほかの機能から呼ぶ入口は `src/store/chorus.ts`（`findChorusIn`・`findSongChorus`・`makeChorusPreview`）、探し方は `src/audio/chorus.ts`（ワーカーで動かします）。
- **フレーズ候補**（ツール › フレーズ候補、右パネルの「小節」）：選んだ範囲（4小節まで）に、フィルやリズムの候補を3つ点線で出します。Tab・, ・. で切り替え、Enter で置き、Ctrl+Z で戻せます。手が3本いる・左足が2つ・HHの開閉が同時、の候補は直してから出します。AI とは拍ごとに細かさを変えられる格子でやりとりするので、3連・32分の候補も設定のグリッドに関係なく出せます。キーが無いときは「似た小節からコピー」と「直前の小節の複製」を出します。
- **AIのレベル判定**（右パネルの「確かめる」）：難易度ガイドラインと手元の似た譜面を物差しにして、機械的な推定では拾えない読みにくさなども考えてレベルを出します。
- **難易度ガイドライン**（ツール › 難易度ガイドライン）：手元の曲フォルダの譜面を集計し、レベル帯（Lv1台〜Lv9台）ごとの要素の出現率、代表の譜面、基準から外れている譜面を出します。帯ごとの基準文は手で書くか AI に下書きさせ、確定すると版が上がります。JSON で書き出し・読み込みできます。
- **AI難易度生成**（上のバーの「✦ AI難易度生成」。難易度の切り替えの隣。ツール › AI難易度生成 からも）：いま開いている譜面を MASTER として BASIC・ADVANCED・EXTREME を作ります。ノーツの配置はルールで行います。音楽の決まりごと（拍の強さ: 小節の頭 > 3拍目 > 2・4拍 > 8分の裏 > 16分の裏、と楽器の役割）で決めた1本の「省く順番」を、曲全体に同じに当てます（左ペダル → スネアのゴースト → 刻みの16分 → バスドラムの16分 → … → 刻みの8分の裏 → バスドラムの8分の裏 → … → 2・4拍のバスドラム → … → 頭と食い以外のキメ → スネアの8分のシンコペーション。順番は画面の「簡略化の段」の説明と同じ）。同じ役割の音は曲のどこにあっても同じ扱いなので、あるセクションではバスドラムを削り、別のセクションではハイハットを削る、といったばらつきは起きません。速い曲（BPM 130 以上）は刻みの8分の裏をバスドラムの8分より先に、遅い曲は後に省きます。いつも残すのは、1拍目のバスドラム・2・4拍のスネア・小節の頭と食い（次の小節の頭の代わりに前の8分の裏で鳴らすもの）のクラッシュとそれに合わせたバスドラム・フィルの着地です。ほかのキメ（裏のクラッシュとそれに合わせた音）も終わり近くの段まで残します。同時打ちは EXTREME あたりまでは3つのままで、そのあとは2つまでにします（まず刻みを抜くので、4つ打ちのバスドラムは残ります。キメは3つのまま）。シンバル・ライド・ハイハットの刻みはどれも同じ細かさ（16分 → 8分 → 4分 → 1・3拍）に粗くします。易しくするのは音を間引くことだけで、楽器や奏法は別のものに置き換えません（ライドはライド、オープンHHはオープン、左シンバルは左のまま。左バスドラムだけは、同じバスドラムなので右へ寄せます）。AI は全体とセクションごとの説明を書き、「AIへの追加の指示」でセクションごとの違いを頼んだとき（例: サビは元の譜面に近く）だけ、セクションの役割（静か: 先にやさしく／山場: 最後まで元に近く）を付けます。指示が無いときは、AI が役割を付けても使いません。役割があっても、どのセクションも曲全体と1段しか違いません。目標のレベルは、難しい曲ほど下の難易度も高くします：いちばん上の譜面から EXTREME は 1.3、ADVANCED は 1.8、BASIC は 2.2 までしか下げません（MASTER が Lv8.6 なら 7.3・6.8・6.4 くらい。BASIC でも元の音の約半分を残し、削りすぎて曲が崩れないようにします）。機械的な推定（元譜面の登録レベルに合わせて換算）が目標のレベルに入る段で止めます（セクションの役割があるときは、段のあいだを静かなセクションから先に次の段にして細かく合わせます）。キーがあれば AI がレベルを判定し、外れていれば1回だけ作り直します。難易度どうしは小節ごとにも逆転しないようにそろえます：上の難易度から順に作り、下の難易度は上の難易度に残した音だけで作り、上の難易度は下の難易度に残した音（曲に既にある譜面なら、同じ時刻・同じ楽器の音）を残します。上の難易度が静かにしたセクションは下の難易度でも静かにし、AI にはほかの難易度がセクションごと・フィルの前後でどれだけ音を残しているかを渡して、考え方を合わせてもらいます。レベルも隣の難易度と 0.3 以上あけます。チップの手直しはほかの難易度にも伝わり（下の難易度にある音は上にも残し、上に無い音は下からも削る）、上の譜面より濃い・下の譜面より薄い小節が残ったときは「段階の逆転」としてその小節を出し、並べた譜面でも琥珀色にします。作った譜面は MASTER と並べて曲全体を1画面に出し（曲全体・16・8・4小節に切り替え、Ctrl+ホイールで拡大縮小）、エディタと同じ操作で再生できます（Space で再生・停止して ▶ に戻る、Shift+Space でここで止める、小節番号の列や空いた所のクリックで ▶ を置く、↑↓ で ▶ を動かす、Home で先頭、I・O・/ で A–B ループ、速さ）。聴く譜面は上の「聴く」、列の見出し、← → で切り替えられ、再生中でも止めずにその場で切り替わります。音量はエディタと同じで、上のマスターと、下の列のトラックごとの M・S・音量（譜面の音・原曲・SE・ステム）で変えられます。チップを押すと残す・削るを手直しできます。「採用してset.defに書き出す」で `*_bsc.dtx`・`*_adv.dtx`・`*_ext.dtx` と set.def（L1〜L4）を曲フォルダに書き出します。

- **難易度を下へ移して、あいだに作る**（AI難易度生成）：遊びたいレベルの譜面が曲の難易度のあいだに無いとき、曲にある譜面を 1 つ下の難易度へ移し、空いた難易度に上下の譜面のあいだのレベルの譜面を作ります。開いている譜面より下の、曲にある譜面のすぐ下の難易度が空いていれば、そのカードに「↓ ○○ へ移して、あいだに作る」が出ます。開いている譜面を移すときは、元の譜面のカードの同じリンクで、すぐ上の譜面を開き直してから移します（新しい譜面は上の譜面を間引いて作るので）。DTXMania の曲の「あいだに作る」から来たときは、移してある状態で開きます（下の難易度が埋まっていれば、2 つ続けて移すこともあります）。
  - 移した譜面のカードには元の難易度（← ADV など）が付き、まだエディタに反映していなければ「戻す」で元に戻せます（空けた難易度で作った結果は消えるので、そのときは聞きます）。
  - 空いた難易度の目標は、上下の譜面のあいだです（難しい曲の下の難易度を上の譜面に合わせて引き上げるのは、上の譜面だけから作るときのものなので、ここではしません）。めやすを入れると、次の曲でもはじめに出します。
  - 移すのは set.def の段と難易度名だけです。譜面のファイルも中身も変えないので、DTXMania の成績（譜面の名前.score.ini）は移した譜面に付いたままです。新しい譜面は別の名前（adv_ai.dtx など）で書きます（古い名前を使うと、前の譜面の成績が新しい譜面に付いてしまうため）。「エディタに反映」で、移すことと新しいファイルの名前を見せてから書きます。反映するまで曲のフォルダは変わりません。
  - しくみ（開発）: どこに作るか・どれを移すかの案は `src/gen/insert.ts`、移す・戻す・反映は `src/store/gen.ts`（`moveDown`・`moveSourceDown`・`undoMove`・`applyInsertPlan`・`writeOut`）、目標は `src/gen/targets.ts` の `inserted`。

AI に送るのは譜面の特徴量・チップの並び・原曲の打点の数値・ガイドラインの文だけで、音そのものは送りません。

## 耳コピ精度テスト

原曲からドラムの打点を推定する方式の当たり具合を、同じ物差しで測ります（[docs/bench.md](bench.md)）。

- `bench.html`（公開版: <https://check5004.github.io/dtx-mania-web-editor/bench.html>）で曲フォルダ（か、曲フォルダがいくつも入ったフォルダ）を選ぶと、譜面を正解にしてテスト曲を作り、方式ごとに F 値を出します。曲のデータはブラウザの中だけで使います。
- テスト曲は「ドラムだけ」「合成（ドラム抜きBGM＋譜面の音）」「実録音（ドラム抜きBGM＋曲に付いている本物のドラム）」「原曲」「ドラム無し（対照）」の5通り。楽器は BD・SD・TT・HH・CY の5種、許容のずれは ±50ms。
- `npm run bench -- <曲フォルダ> [--full BGMがドラム入りの曲名]` でヘッドレスの Chromium で回し、`bench-results/` に JSON と Markdown を書き出します（Playwright が要ります）。
- 外した候補チップ（v0）は、実録音で F 0.30（候補の8割が外れ）、ドラムの無い音でも 0.26 でした。ドラムの採譜モデル（ADTOF）は実録音で 0.68、ドラムの無い音で 0.02 です。
- 同じページの「TAB補完を測る」（スクリプトは `--complete`）で、TAB補完が先の1〜4小節をどれだけ当てるかを測ります。

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # DTXの読み書き・タイミング・編集操作・解析・テンポ合わせ・ライブラリ・AI機能・精度テストの仕組み・ステム分解の信号処理のテスト、Safari の決まりの検査
npm run build    # 型チェックとビルド（dist/）
```

Safari（iPad）で動かなくなりやすい書き方（タップの外で音を鳴らし始める、Safari に無い API など）は `npm test` が止めます（`scripts/safari-check.mjs`、単独でも `node scripts/safari-check.mjs`）。引っかかったら [docs/safari.md](safari.md) を読んで直すか、確かめて表に足します。

公開は `npm run deploy` で行います。ビルドした `dist` を `gh-pages` ブランチに置き、GitHub Pages はそのブランチから配信します（Settings → Pages → Deploy from a branch → `gh-pages` / `(root)`）。

標準キットの音（`public/kits/`）は `node scripts/make-kits.mjs --src <音源のフォルダ> [--only キット,…]` で作り直せます（作り方は `scripts/kits/defs.mjs`、音源の取り方は [scripts/kits/SOURCES.md](../scripts/kits/SOURCES.md)。`ffmpeg` と開発用の `spessasynth_core` を使います）。

アプリのアイコン・ファビコン・iPad の起動画面は、絵（`scripts/icon-art.mjs`）から `node scripts/make-pwa-images.mjs` で作ります。README の図（`docs/readme/*.svg`、アニメーションは CSS だけ）と画面写真（`docs/readme/shots/`）は `scripts/readme/` で作り直せます（オリジナルのデモ曲 `demo-song.mjs`、図 `make-svgs.mjs`、開発サーバーでの撮影 `shots.mjs`、iPad・iPhone を並べる `devices.mjs`、PNG を軽くする `shrink.py`。使い方は各ファイルの頭）。画面写真に実在の曲は写しません。

GitHub Actions で自動公開したい場合は、`docs/deploy-workflow.yml` を `.github/workflows/deploy.yml` に置いて、Pages の Source を「GitHub Actions」に切り替えてください。
